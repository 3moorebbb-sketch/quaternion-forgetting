    Method findings · S³ network, shared defaults, 16 seeds

    Protect outputs, not weights

    At matched Task B accuracy (≥95% at step 1,000), anchoring Task A's outputs on 100 stored inputs keeps 96.0 ± 1.4%. Anchoring the weights keeps 73.5 ± 7.0%. Raising λ only trades one task for the other: λ = 2 gives 92 / 67.

    Static OGD decays from linearisation drift, not S³ curvature

    With a frozen basis, T-OGD ends at 55–64% for every K from 1 to 62, even though K = 15 captures 99.8% of the gradient energy. Recomputing the same projection every 10 steps lifts it to 95.4 ± 1.3%. Every 50 steps gives 84%. On split-head or real networks, static OGD already holds 95–97%, so the drift is this large mainly because both tasks share one output.

    Replay is the bar, and three methods meet it

    With 100 stored points, output anchoring, replay and refreshed OGD all land at 95–96% on Task A and 97–98.5% on B. Refreshed OGD costs about 25–45× more compute per step (100 Jacobian rows plus an eigensolve each refresh).

    Small memory favours soft targets

    The shared i/j readout is the weak point

    Both heads read the same output quaternion, so every weight serves both tasks. Unprotected SGD falls to 54.3%, below the this grid gives for predicting "outside" everywhere. The architecture study shows this readout, more than the S³ constraint, drives the forgetting.

    Single runs vary

    Per-seed spread at step 1,000 is ±1–2 points for the three memory methods and ±6–7 for the weight anchor and static OGD. One live run can sit 10 points from the mean, so use the benchmark before drawing conclusions.

    Protocol and fairness
    • Network: 1→6→6→1 quaternion neurons. The weight is A·q with ‖q‖ = 1, the hidden activation is split-tanh and the output is linear. The heads are z_A = 3.5·out_i and z_B = 3.5·out_j. Backprop was checked against finite differences (max relative error 2e-6).
    • Optimiser: q takes an exponential-map step on S³ after tangent projection. A and b take Euclidean steps, with A ≥ 0.01. Task B uses plain Riemannian SGD at lr 0.035 with batch 20.
    • Task A checkpoint: trained with Riemannian Adam until the fixed grid reads ≥ 95%, restarting from a fresh init if needed. All 16 reference seeds passed on the first attempt, at 95.3–99.0%.
    • Shared memory: each seed stores the same 100 uniform inputs. Replay uses their labels, the output anchor uses the checkpoint logits, and OGD uses the checkpoint's output gradients (static) or the current ones (refreshed). Memory minibatches are 20 points, with indices shared across methods each step.
    • Evaluation: a fixed 50×50 grid on [−1, 1]², so readouts carry no sampling noise. Majority floor = : the share of grid points outside the circle. That's higher than the circle's area fraction (64.7%) because the grid includes the edges and corners. The 50% line is what any half-plane through the origin scores on Task A.
    • Knob choice: each method's default is its best Task A accuracy at step 1,000 subject to Task B ≥ 95%, chosen from the sweep in the Pareto plot. The two OGD variants share K = 15, so they differ only in refresh.
    • Networks: . The free quaternion networks start from exactly the same function as their S³ counterparts (w = A·q at init). Only the parameterisation and update geometry differ.
    • Architecture study: each method's learning rate ∈ {0.0175, 0.035, 0.07} and knob (λ ∈ {0.01, 0.05, 0.2, 1}, μ ∈ {0.01, 0.03, 0.1, 0.3}, ρ ∈ {0.25, 0.5, 1, 2}, static K ∈ {5, 15, 40}; refreshed OGD K = 15 every 10 steps) were chosen on seeds 1–6, by best Task A at step 1,000 subject to Task B ≥ 95%, then reported on held-out seeds 7–12. The SGD 2×2 result was confirmed on fresh seeds 13–36. Every network reached a ≥ 95% checkpoint on every seed. The S³-cost ablations (ablate.js) start every variant from the same S³ split-head checkpoint with the same Task B batches, and compare them paired over seeds 13–36. adam.js repeats the comparisons with Adam for Task B (lr 0.0025–0.01). probe.js fits exact logistic-regression probes on the last hidden layer (2,000 random points, scored on the grid) and refits the readout from the 100-point memory.
    • Intervals: 95% percentile bootstrap of the difference in means, 10,000 resamples. One exploratory result, a +2.6-point edge for free split-head quaternions over the 282-parameter MLP, did not replicate on the fresh seeds and is reported as null.
    • Seeds: checkpoint RNG = seed·7919+1, memory = +2, Task B stream = seed·104729+3 (mulberry32).
